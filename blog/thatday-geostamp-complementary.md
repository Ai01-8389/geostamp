# That Day + GeoStamp：照片记忆保留的完整方案

> 时间、地点、故事——三要素缺一不可

---

## 一、理解 That Day

**That Day**（thatday.vip）是一个桌面端个人照片记忆工具。

### 核心逻辑

不是按文件夹看照片，而是按「**每年同一天**」来浏览。

举个例子：
> 你选 7月4日 → That Day 会把你 **2018年7月4日、2020年7月4日、2023年7月4日** 的照片全部列在一屏里。

十年的人生，用一个日期维度压缩到一页。

### 核心功能

| 功能 | 说明 |
|------|------|
| 照片扫描 | 扫描本地照片库，按「日历日」跨年份分组 |
| 三词标注 | 每张照片回答：谁？在哪？在做什么？——打字或说话都行 |
| AI写故事 | AI根据三个词生成一段个人叙事（英文） |
| 语音朗读 | 每天早8点邮箱收到故事 + 英文语音朗读 |
| PDF纪念册 | 每篇故事可导出为PDF，含封面、照片、完整叙事 |
| 隐私 | 照片留在本地，只有标注和故事同步到云端 |
| 价格 | $9.79/月，7天免费试用 |

### 它解决什么问题

- 你的手机有几万张照片，但你几乎不去翻
- 照片有日期，但没有「故事」——你不知道那天发生了什么、和谁在一起
- 每年的同一天在做什么？这个问题几乎没人能回答——That Day 给出了答案

### 它的局限性

- **只加了故事，没有把「地点」固定在照片上**
- 三字标注中的「Where?」存在That Day的云端，照片本身没有位置水印
- 如果停止订阅或服务关闭，故事和位置信息就丢了
- 语音和PDF很美，但照片本身仍然是「沉默的」

## 二、GeoStamp + That Day：互补方案

这两个工具分别解决记忆保留中**两个不同的维度**：

```
                   记忆保留
                  /        \
         GeoStamp             That Day
      (地点 + 时间)          (故事 + 语音)
        埋入照片               生成叙事
        永久可见               每日送达
```

### 维度对比

| 维度 | GeoStamp | That Day |
|------|----------|----------|
| 时间 | ✅ 精确到秒，印在照片上 | ✅ 跨年份按日历日聚合 |
| 地点 | ✅ GPS坐标+城市名，永久印在照片上 | ⚠️ 三词标注中有"在哪"，但存在云端 |
| 人物 | ❌ 不涉及 | ✅ 三词标注"和谁" |
| 事件 | ❌ 不涉及 | ✅ AI生成完整故事 |
| 语音 | ❌ | ✅ 英语语音朗读 |
| PDF | ❌ | ✅ 每日PDF纪念册 |
| 永久性 | ✅ 水印在照片上，和JPEG同寿命 | ⚠️ 依赖服务持续运行 |
| 本地处理 | ✅ 全本地 | ✅ 照片本地，故事同步 |

### 互补关系

**GeoStamp 负责「证据层」——把时间和地点永久烙在照片上：**

- 每张照片离开手机后，GPS坐标、城市名、日期时间就被刻在图像中
- 30年后打开这张JPEG，地点还在
- 无论用哪个软件看，位置信息一直都在

**That Day 负责「叙事层」——为照片赋予故事和情感：**

- 知道了时间和地点，但不知道和谁、因为什么
- That Day 通过三词标注 + AI，把「数据」变成了「故事」
- 语音朗读让记忆可以「听」，PDF让记忆可以「印」

## 三、完整工作流

把两个工具串联起来，就是一个从拍摄到永久记忆的完整流水线：

```
拍照（手机，带GPS）
    ↓
GeoStamp → 印上GPS坐标 + 城市 + 日期
    ↓
存入照片库
    ↓
That Day → 扫描照片 → 按日历日分组
    ↓
三词标注：谁？在哪？做什么？
    ↓
AI生成故事 + 语音
    ↓
每日早8点邮箱送达 + PDF
```

**结果：** 一张照片获得了三层信息——

1. **视觉层：** GeoStamp印在照片上的坐标和时间（永久、显性）
2. **叙事层：** That Day生成的故事和语音（可听、可读）
3. **存档层：** PDF纪念册（可打印、可分享）

## 四、谁更需要这个组合

### 1. 长期旅行者 / 数字游民

每年去不同国家，照片上万张。GeoStamp告诉你"在哪拍的"，That Day告诉你"那天发生了什么"。

### 2. 家庭记忆记录者

孩子的成长照片横跨十年。GeoStamp给每张照片留下地址（"这是我们当时在波特兰的家"），That Day让每一年的生日、暑假、圣诞都有完整故事。

### 3. 年长的父母

照片是留给子女的遗产。GeoStamp确保每张照片的地点不丢失，That Day生成的故事和语音可以让孩子"听妈妈读她的日记"。

### 4. 个人历史爱好者

有人在坚持做"每日一记"十年了。GeoStamp在照片层面留下痕迹，That Day在叙事层面串联时间线。

## 五、对GeoStamp的意义

That Day 是 GeoStamp 理想的**互补推广伙伴**，原因如下：

1. **用户画像高度重叠**——Both appeal to people who care about photo preservation
2. **没有竞争关系**——一个标地点，一个写故事
3. **可互相推荐**——GeoStamp blog可提"That Day帮你讲照片背后的故事"，That Day blog可提"先用GeoStamp把位置印在照片上"
4. **联合价值主张更强**——“地点+故事=完整记忆”

一个可能的合作方式：
> GeoStamp博客写一篇关于That Day的指南，That Day在app内或博客推荐GeoStamp作为照片预处理工具。
