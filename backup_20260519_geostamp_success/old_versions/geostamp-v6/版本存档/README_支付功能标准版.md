### 功能特性
1. **Creem.io 支付集成**
   - 完整的支付流程（创建checkout、支付验证）

5. **免费/订阅模式**
   - 免费用户：每次最多处理 1 张图片
   - 订阅用户：无限批量处理
   - 订阅状态保存在 localStorage
