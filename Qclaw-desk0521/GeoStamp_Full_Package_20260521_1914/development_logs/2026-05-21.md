### Problem
- App window displayed but login buttons had no response
- User reported "无反应也无任何错误提示"

### Investigation
1. **vite.config.js Port Mismatch**: Vite running on 1421 but Tauri config expected 1420
   - Fixed: Changed vite.config.js to `port: 1420, strictPort: true`
   
2. **Tauri Process Status**: Process was being killed with SIGKILL
   - Found process was actually running but window was minimized/hidden
   - Used `SetForegroundWindow` to bring window to front

3. **Window Visibility**: Window existed (title "GeoStamp") but not visible
   - Fixed by bringing to foreground with PowerShell

### Solution Applied
- Ensure vite.config.js and tauri.conf.json use same port (1420)
- Use `Add-Type` + `SetForegroundWindow` to bring Tauri window to front
- Process: `Get-Process | Where-Object {$_.MainWindowTitle -like "*GeoStamp*"}`
